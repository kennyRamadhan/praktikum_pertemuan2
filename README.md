# Belajar Dasar HTML

Praktikum sederhana membuat halaman **Profil Mahasiswa** untuk mengenal tag-tag dasar HTML. Buka `index.html` di browser untuk melihat hasilnya.

## Langkah-langkah

1. **Menambahkan Judul** — pakai `<h1>`–`<h3>` untuk judul dan subjudul halaman.
2. **Menambahkan Paragraf** — pakai `<p>` untuk menulis teks biasa.
3. **Memformat Teks** — pakai `<b>`/`<strong>` (tebal), `<i>` (miring), `<sub>` dan `<sup>` (subskrip/superskrip).
4. **Menambahkan Gambar** — pakai `<img>` dengan atribut `src`, `width`, `height`, `alt`, dan `title`.
5. **Menambahkan List** — pakai `<ul>` untuk daftar tak berurut dan `<ol>` untuk daftar berurut, isinya `<li>`.

## Struktur Folder

```
Praktikum/
├── index.html      # halaman utama
├── images/         # gambar (profile.jpg)
├── step/           # screenshot tiap langkah
└── README.md
```
